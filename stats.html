How to read these

  • Each day is every resort's last report of that day, so today can still change.
  • Lifts, slopes and km count open resorts only.
  • Coverage grew while history was collected: Resorts tracked shows it. A rise can come from a newly added country rather than from resorts opening.
  • Some open resorts report no km, so Open slopes (km) runs low.
